# 🚀 Simple Clarivo Guide

## ⚡ Quick Start (2 Steps)

### Step 1: Setup
```bash
# Run the simple setup
setup-simple.bat
```

### Step 2: Launch
```bash
# Choose one of these:

# Option A: Web Version (Recommended)
start-clarivo-working.bat

# Option B: Desktop Version
start-electron-simple.bat
```

## 🎯 That's It!

The application will:
- ✅ Install frontend dependencies
- ✅ Start the React development server
- ✅ Open in your browser (web version)
- ✅ Or open as desktop app (Electron version)

## 📁 Available Scripts

### For Quick Start:
- **`setup-simple.bat`** - Simple setup (no backend)
- **`start-clarivo-working.bat`** - Web version (recommended)
- **`start-electron-simple.bat`** - Desktop version

### For Stopping:
- **`stop.bat`** - Stop all processes

## 🌐 Access Points

- **Web Browser**: http://localhost:3000
- **Desktop App**: Opens automatically (if using Electron)

## 🔧 Troubleshooting

### If it doesn't work:
1. **Run setup first**: `setup-simple.bat`
2. **Try web version**: `start-clarivo-working.bat`
3. **Check ports**: Make sure nothing is using port 3000
4. **Kill processes**: `stop.bat` then try again

### Common Issues:
- **"Port already in use"**: Run `stop.bat` first
- **"Node.js not found"**: Install Node.js from [nodejs.org](https://nodejs.org)
- **"npm not found"**: Install Node.js (includes npm)
